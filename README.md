# Rediseño Gimnasia y Esgrima La Plata

Landing implementada desde Figma en HTML, CSS y JavaScript sin dependencias.

- `index.html` — estructura de la página
- `styles.css` — estilos y animaciones (hover, reveal, navbar glass → sólida)
- `script.js` — interacciones (scroll-spy, parallax, tilt 3D, lightbox, menú móvil)
- `assets/` — imágenes y logos exportados de Figma
